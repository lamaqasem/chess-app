# أكاديمية الشطرنج: تحويلها إلى تطبيق

## الطريقة الأسهل: تثبيت كتطبيق (بدون APK)
1. ارفع مجلد `www` على https://app.netlify.com/drop (اسحبه وأفلته، يعطيك رابطاً).
2. افتح الرابط في Chrome على الجوال > قائمة ⋮ > «تثبيت التطبيق».
   (آيفون: Safari > مشاركة > إضافة إلى الشاشة الرئيسية)
بعد أول فتح تعمل اللعبة بدون إنترنت.

## ملف APK لأندرويد
1. أنشئ حساباً مجانياً على GitHub ومستودعاً جديداً.
2. ارفع كل محتويات هذا المجلد (ملفات www و package.json و capacitor.config.json).
3. أنشئ ملفاً جديداً في المستودع باسم `.github/workflows/android.yml` والصق فيه محتوى الملف الموجود في هذا المجلد.
4. من تبويب Actions شغّل «Build Android APK»، وعند انتهائه نزّل ملف chess-apk من قسم Artifacts، وثبّته على جوالك.
(ملف debug، فيسألك أندرويد السماح بالتثبيت من مصدر غير معروف.)
آيفون: لا يمكن عمل تطبيق حقيقي بدون جهاز Mac وحساب مطوّر مدفوع، فاستخدم الطريقة الأولى.
